# Folio — демо дашборда для фрилансеров

Портфолио-копия кабинета «заказы, доходы, расходы»: тот же интерфейс и функционал, но без базы, бота и входа.
При каждом заходе на сайт посетитель сначала выбирает профессию (10 вариантов: веб-дизайнер, фотограф, видеограф, графический
дизайнер, SMM, ремонт, репетитор, мастер красоты, психолог, фитнес-тренер) — под неё меняются подписи
(«Заказы» → «Съёмки», «Ученики», «Объекты»…) и демо-данные за год. Все данные вымышленные и хранятся в браузере
(localStorage), у каждой профессии своя копия. Сменить профессию и сбросить данные — в «Профиле».

## Запуск

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # проверка сборки
```

Сайт собирается в статику (`output: "export"`, папка `out`) и публикуется на GitHub Pages сам при каждом пуше в `main` —
см. `.github/workflows/deploy.yml`. В настройках репозитория: Settings → Pages → Source → «GitHub Actions».
Переменные окружения не нужны.

## Как устроено

| Файл | Что делает |
| --- | --- |
| `src/lib/professions.ts` | Список профессий и словарь слов интерфейса для каждой (с падежами) |
| `src/lib/seeds.ts` | Демо-данные каждой профессии: клиенты, оплаты, траты, заметки, план |
| `src/lib/demo.ts` | Сборка данных из описания профессии; даты считаются от «сегодня» |
| `src/components/ProfessionPicker.tsx` | Окно «Кто вы по профессии?» при каждом заходе и смена профессии из профиля |
| `src/components/terms.ts` | `useTerms()` — слова выбранной профессии для компонентов |
| `src/lib/store.ts` | Хранилище в localStorage: загрузка, сдвиг дат при следующем визите (демо не стареет), сброс |
| `src/app/actions.ts` | Сохранение и удаление — те же функции, что в рабочей версии, только пишут в хранилище браузера |
| `src/lib/data.ts` | `useAppData()` — данные для экранов; правки сразу перерисовывают все вкладки |
| `src/components/WithData.tsx` | Подставляет данные в экраны и показывает заглушку до чтения хранилища |
| `src/lib/env.ts` | Название кабинета (`APP_NAME`) и подпись |

Если поменять демо-данные в `seeds.ts`, у тех, кто уже открывал сайт, останется старая копия — увеличьте `VERSION`
в `store.ts`, чтобы всем загрузились новые.

Фон — `public/bg.webp` (ПК) и заранее размытый `public/bg-blur.webp` (телефон).
